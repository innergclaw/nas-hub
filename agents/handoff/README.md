# INNERG INTEL ~ Agent Handoff

The shared record between Mr G's agents (Claude, InnerG Studio, Grokbot and any future agent). Every agent follows these rules so it stays organized instead of turning into one long file.

## Files
- **One file per workstream**, named `<area>.md` with a matching `<area>.json`:
  - `video-edit` ~ YouTube, Shorts, TikTok, Instagram video (Me & My Agent Wednesday, Financial Frequency Friday, Frequency videos)
  - New areas get their own file when work starts, e.g. `web-ownyourweb`, `imunch-site`, `innerg-reads`, `products`.
- **Inside a file**, one section per series or project, and one block per episode or task.
- **Split** a series into its own file (`<area>-<series>.md`) when it has more than 5 active items or the file passes ~300 lines.
- **Archive** anything that has been done (live, delivered, closed) for 14+ days into `archive/YYYY-MM.md`. Keep a one-line pointer in the main file.
- Every update changes the "Last updated" line (time ET + which agent).

## Index
| Workstream | File | Slack |
|---|---|---|
| Video editing | `video-edit.md` / `.json` | `#innerg-agents` |

Add a row whenever a new file or channel is created.

## Slack
- **`#innerg-agents` is the hub**: cross-workstream pings and announcements of new files or channels.
- **One thread per episode or task.** The first message names it (e.g. `FFF Ep. 002 ~ ...`); every later update on it goes in that thread, not a new top-level post.
- **A workstream gets its own channel** (`#innerg-<area>`, e.g. `#innerg-video`, `#innerg-web`) once it has 3+ top-level pings in a week, or it is a separate business. The agent that creates it posts one line in `#innerg-agents` and adds it to the Index above.
- One-line pings only. Details live in the handoff files.

## Shared rules
- Never write the word "AI" (use "SI" or "superintelligence"); no em dashes (use "~"); no invented facts or numbers.
- Nothing gets published, scheduled, rescheduled or deleted without Mr G's explicit yes.
- When Mr G sends ✅ to an agent, that agent updates its handoff file and pings Slack.
